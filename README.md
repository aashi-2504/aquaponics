>>Acquisition and Analysis of Aquaponics Systems

This project focuses on predicting crop yield in an aquaponics system using machine learning techniques.
Environmental and chemical parameters are used as inputs to support data-driven agricultural decisions.

>>Technologies Used
- Python
- Flask
- scikit-learn
- Machine Learning

>> Project Overview
The goal of this project is to analyze aquaponics data and build a predictive model for crop yield.
Multiple machine learning models were trained and evaluated to identify a stable and accurate solution.

>> Models Used
- Random Forest
- Gradient Boosting
